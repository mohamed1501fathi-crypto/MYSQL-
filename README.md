MySQL Assignment – DDL Commands & Constraints

📌 Project Overview

This project is a MySQL assignment completed as part of my Data Analytics learning journey.

The main objective of this assignment was to practice DDL commands and understand how to use constraints while creating and modifying database tables.

🛠️ Tools Used

- MySQL
- MySQL Workbench
- GitHub

📂 Database

Database Name: "employee"

Tables

- "Departments_Info"
- "Locations"
- "employees"

📋 Part 1 – DDL Commands

In Part 1, I practiced the following DDL commands:

- "CREATE" – Created the database and tables
- "ALTER" – Added, modified, dropped, and renamed columns
- "RENAME" – Renamed tables
- "TRUNCATE" – Removed all records from a table
- "DROP" – Deleted a table and database

🔐 Part 2 – Constraints

I implemented different MySQL constraints, including:

- PRIMARY KEY – Uniquely identifies records
- NOT NULL – Prevents empty values
- UNIQUE – Prevents duplicate values
- AUTO_INCREMENT – Automatically generates sequential IDs
- ENUM – Restricts gender values to "M" or "F"
- CHECK – Ensures age is 18 or above
- DEFAULT – Automatically assigns the current date to "hire_date"
- FOREIGN KEY – Connects employees with departments and locations

🎯 Learning Outcome

Through this assignment, I gained practical experience in creating databases and tables, modifying table structures, applying constraints, and establishing relationships between tables using MySQL.
